# TO-DO

A simple to-do list web application built with HTML, CSS, and JavaScript.

## Features

- Add new tasks using the input field
- Mark a task as done with a strike-through effect
- Remove tasks from the list
- Responsive and lightweight browser-based interface

## Project Structure

- `index.html` – main page structure
- `style.css` – styling for the app
- `second.css` – additional stylesheet
- `one.js` – task logic and event handling
- `second.html` – secondary HTML page

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Type a task in the input box and click the `+` button to add it.

## Notes

This is a beginner-friendly front-end project demonstrating DOM manipulation and event handling in JavaScript.
